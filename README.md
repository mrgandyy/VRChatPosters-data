# FBT Social world data

Public asset feed for the FBT Social VRChat world, served from GitHub Pages at
`https://mrgandyy.github.io/VRChatPosters-data/`.

The FBT Social bot publishes everything here automatically: `catalog.json`, the poster sheets in `atlases/`,
premium `billboards/`, `backdrops/` and `booths/`, `studio/` textures, `performers/` stage art,
`performers.json` and `heat.json`. Files no catalog entry uses are removed as new art is published.
The bot's code is private.
