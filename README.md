# FBT Social world data

Public asset feed for the FBT Social VRChat world, served from GitHub Pages at
`https://mrgandyy.github.io/VRChatPosters-data/`.

The Wreckshop Worlds bot (`wreckshop-service/`) publishes everything here: `catalog.json`, the poster sheets in
`atlases/`, premium `billboards/`, `backdrops/` and `booths/`, `studio/` textures, `performers/` stage art,
`performers.json` and `heat.json`. See `wreckshop-service/README.md`.

The old poster system (`poster_uploads/` and `poster_mapping.json`) was retired and removed in October 2026.
